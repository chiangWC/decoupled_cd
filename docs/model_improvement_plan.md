# Model Improvement Plan

这份文档记录当前模型改进工作的状态、已经完成的实验，以及下一轮应优先推进的方向。它不是正式规范，作用是避免后续继续重复已经验证过的改动。

## 当前状态

当前项目已经具备:

- Step 1-4 的最小可运行闭环
- `train / valid / test` 评估链路
- GPU 全量训练能力
- `assist_09` 上多轮完整对比实验

当前问题不再是“工程跑不通”，而是“模型有效信号不足”。

## 已完成实验

### 1. 原始 Q 共现图基线

特点:

- `N(k)` 由 Q 矩阵裸共现图构造
- `q_e` 使用题目所需知识点 embedding 的简单平均

结果:

- `assist_09` 20 epoch 全量训练可稳定运行
- 指标略高于随机，但提升有限

### 2. 稀疏归一化共现图 + 可学习 `q_e`

改动:

- `N(k)` 改为归一化共现 + top-k 稀疏图
- `q_e` 改为可学习加权汇聚 + MLP

实验结论:

- 训练稳定
- 没有形成稳定泛化收益
- `test_auc` 只有微小变化，`val_auc` 反而更差

结论:

- 这轮改动不能作为当前主基线

### 3. 论文式转移图

改动:

- 基于有序版 ASSIST09 数据
- 使用论文风格的 `C / T` 关系构建方法
- 导出:
  - `prerequisite_graph`
  - `similarity_graph`
  - `propagation_graph`

当前结果:

- 先修边数: `1161`
- 相似边数: `2492`
- 在 `assist_09` 上 20 epoch 全量训练取得当前最好 `test_auc`

结论:

- 这版图比前两版更值得作为后续改造基线

## 当前推荐基线

后续模型改动应默认建立在下面这组设置上:

- 数据: `data/assist_09_ordered/`
- Q 矩阵: `data/assist_09_ordered/Q_matrix.csv`
- 知识图: `data/assist_09_ordered/transition_graph/propagation_graph.csv`
- 训练入口: [train.py](/home/xph/jwc/research/decoupled_cd/scripts/train.py)

## 当前主要瓶颈

在当前基线下，主要问题已经收敛到以下几点:

- `TKC` 分支里，行为消息与知识邻接消息仍然是简单相加
- `g_u / s_u` 仍然只是学生级常数
- `UKC` 分支虽已有更合理的结构图，但传播方式仍较朴素
- 题目表示 `q_e` 虽已升级，但仍未与学生状态产生足够强的区分性

## 下一轮优先级

### 1. 优先改 `TKC` 两路消息融合

目标:

- 把 `exercise/behavior` 消息和 `concept neighbor` 消息拆开建模
- 不再默认同权相加

建议:

- 为两路消息引入独立可学习权重
- 或使用 gated fusion

原因:

- 这是 Step 2 中最直接的结构瓶颈
- 也最可能带来稳定增益

### 2. 再改 `g / s`

目标:

- 让非认知因素从学生常数升级为更细粒度建模

建议:

- 先做 `student + exercise` 偏置
- 再考虑条件化 `g_{u,e}` / `s_{u,e}`

原因:

- 当前 Step 3 的非认知部分表达力过弱

### 3. 最后再细调图构建

目标:

- 不是重新发明一张图，而是在论文式转移图基础上微调

建议:

- 重新审视阈值策略
- 重新处理多知识点题目的转移规则
- 观察相似边过多是否影响效果

原因:

- 论文式图已经优于前两版
- 因此当前不建议大幅回退或推翻

## 当前不建议优先做的事

- 不建议继续单纯增加 epoch
- 不建议回到裸 Q 共现图
- 不建议在当前阶段同时大改 `N(k)`、`q_e`、`g/s` 和训练目标

原因:

- 当前已经有可训练、可评估、可比较的基线
- 现在最需要的是可解释的单变量改动

## 下一步执行建议

建议按下面顺序推进:

1. 基于论文式转移图保留当前基线
2. 实现 `TKC` 两路消息的可学习融合
3. 做一轮 `assist_09` 全量训练对比
4. 若仍无明显提升，再升级 `g/s`
