## 结论

1. **砍适配器是目前最大的单一正效应**：v1 全适配器在 zero 桶稳定垫底（两种划分一致，−2.4~−2.5pt vs 裸核/base），其整体涨幅完全来自有历史证据的切片。适配器 = 计数补丁、非诊断能力，实证成立。
2. **B0 角色反转（论文动机素材）**：随机划分整体 AUC 全场第一；留出 zero 桶跌至中游（目标知识点计数被构造归零）——但校准（Brier/ECE）仍全场最佳。整体 AUC 战场属于计数统计，未测知识点排序战场才属于结构模型。
3. **模块 1（TKC→UKC 个性化传播）单独无效，但机制有信号**：
   - 单独加：与 v2 base 完全持平（5 seeds，CI 重叠）；残差权重范数 3.0-3.9（与静态变换同量级）——通路被训练激活，非优化失败。
   - 机制解释（双重静音）：(a) base 读出只经 `mean(UKC 全部概念)` 消费逐知识点状态，个性化被 ~120× 稀释；(b) gate 诊断显示融合门饱和于 TKC 侧（mean w=0.92，UKC 贡献范数 1/11，corr(coverage,w)=0.14）。
   - 配合模块 2（读出可见逐知识点状态）时 **+1.1pt**（m2+m1 0.7285 vs m2 单独 0.7173，~1.5σ，方向在 1/2 层一致）——个性化信号存在，但需要能消费它的读出。
4. **模块 2（目标感知读出）拟合力缺口是当前瓶颈**：单独 −2.4pt vs base（zero 桶）。它解锁掌握度输出/DOA（价值判据未跑），但作为预测头明显弱于池化 NCF。加模块 1 可回补一半缺口，仍低于 base。
5. **模块 3**：3a（单调）在模块 2 之上小幅为正且 ECE 改善；3b（有界 g/s）中性偏负。价值判据（可辨识性/DOA）未跑。

## 已知方法学局限

- checkpoint/早停按**整体** valid AUC 选择，对"牺牲整体换 zero 桶"的模块方向存在系统性选择偏差（待用 loss/分桶指标复测）。
- m2 系仅 3-4 seeds，±1pt 级差异需补 seeds。
- zero 桶 label_rate（0.787）与 full 桶（0.654）不同，桶间不可比，仅同桶跨模型比较有效。
- B0/v1_official 尚为单 seed。

## 下一步（按预期收益排序）

1. 强化模块 2 读出的拟合力（池化 NCF 路径 + 目标感知残差并联，或 per-concept scorer 加入习题嵌入），再测 m1 增量。
2. 处理门控饱和：题级构成感知融合（模块 2 设计里本有）替代全局 w_u，或对 w 加覆盖率先验正则。
3. DOA / 掌握度评测（模块 2/3 的真正判据），用 `--v2-target-aware-readout` 的 mastery 输出。
4. checkpoint 选择指标敏感性（loss vs auc）复测模块 1。
5. m2 系补 seeds；B0/v1_official 补 seeds。

# 追加 4：r11-r12——手术 v2（辅助 BCE）成功、调参、外部基线 DOA（2026-07-07 凌晨，seed=42）

## 本两日实验总账（r1-r13）

min_responses（默认可设 3）+ 概念级 bootstrap 95% CI + Spearman 伴随指标。上表 CI 已用于判定显著性（nips34 分离、assist09 重叠但偏移）。

**留，作为图密度定律的边界证据点。** 标准划分证实 assist09/xes 的预测劣势是低图密度的必然（定律预测），而非模型缺陷；且 aux 插件在 assist09 上仍 +2.8pt DOA。删掉会失去定律的低密度锚点且招审稿人质疑。叙事定位：不是"我们最强"，而是"诊断评测协议 + 图密度定律 + 可移植诊断增强"，assist09 是定律的朋友。

## 核心发现：Mo-1 在模型内部复现了"响应图=预测 / 概念解耦=诊断"的权衡

## 修正与结论更新

- 早前"模块 1(2层) 是唯一 holdout DOA > 0.5 的配置"系单 seed 结论，多 seed 后**不成立**（2/3 seeds 为正、1/3 为负）。成立的是结构性发现：模块 1 是唯一产生留出个性化（非平局）的机制。
- 核心诊断：**当前损失中没有任何项对 UKC 侧掌握度施加训练压力**（BCE 只作用于有作答的交互），个性化状态排序接近随机是预期后果。下一个明确杠杆 = 研究计划中的模块 4 弱版本（掩码 TKC→伪 UKC 的状态一致性目标，不接触标签，保住"无直接行为监督"主张），给模块 1 提供针对推断状态的训练信号。
- 读出层结论：hybrid 可作为论文默认读出（拟合持平 + 掌握度输出）；单调约束应默认开启（掌握度定向）；tfusion 备选。
