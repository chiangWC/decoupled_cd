# assist_09 v2 单模块归因实验记录（2026-07-06）

数据：KnoField assist_09（S=2493, E=17676, K=123）。两种划分：随机作答划分（r2）、严格学生-知识点留出（r3-r5，731 名学生 strict holdout，图策略 train-only）。概念图：Q 共现（未用外部转移图）。统一超参：epochs 300、lr 1e-3、dim 64、早停 patience 5、checkpoint 按整体 valid AUC 选择。服务器 4×RTX 4090。

## 结论

1. **砍适配器是目前最大的单一正效应**：v1 全适配器在 zero 桶稳定垫底（两种划分一致，−2.4~−2.5pt vs 裸核/base），其整体涨幅完全来自有历史证据的切片。适配器 = 计数补丁、非诊断能力，实证成立。
2. **B0 角色反转（论文动机素材）**：随机划分整体 AUC 全场第一；留出 zero 桶跌至中游（目标知识点计数被构造归零）——但校准（Brier/ECE）仍全场最佳。整体 AUC 战场属于计数统计，未测知识点排序战场才属于结构模型。
3. **模块 1（TKC→UKC 个性化传播）单独无效，但机制有信号**：
   - 单独加：与 v2 base 完全持平（5 seeds，CI 重叠）；残差权重范数 3.0-3.9（与静态变换同量级）——通路被训练激活，非优化失败。
   - 机制解释（双重静音）：(a) base 读出只经 `mean(UKC 全部概念)` 消费逐知识点状态，个性化被 ~120× 稀释；(b) gate 诊断显示融合门饱和于 TKC 侧（mean w=0.92，UKC 贡献范数 1/11，corr(coverage,w)=0.14）。
   - 配合模块 2（读出可见逐知识点状态）时 **+1.1pt**（m2+m1 0.7285 vs m2 单独 0.7173，~1.5σ，方向在 1/2 层一致）——个性化信号存在，但需要能消费它的读出。
4. **模块 2（目标感知读出）拟合力缺口是当前瓶颈**：单独 −2.4pt vs base（zero 桶）。它解锁掌握度输出/DOA（价值判据未跑），但作为预测头明显弱于池化 NCF。加模块 1 可回补一半缺口，仍低于 base。
5. **模块 3**：3a（单调）在模块 2 之上小幅为正且 ECE 改善；3b（有界 g/s）中性偏负。价值判据（可辨识性/DOA）未跑。

## 已知方法学局限

- checkpoint/早停按**整体** valid AUC 选择，对"牺牲整体换 zero 桶"的模块方向存在系统性选择偏差（待用 loss/分桶指标复测）。
- m2 系仅 3-4 seeds，±1pt 级差异需补 seeds。
- zero 桶 label_rate（0.787）与 full 桶（0.654）不同，桶间不可比，仅同桶跨模型比较有效。
- B0/v1_official 尚为单 seed。

## 下一步（按预期收益排序）

1. 强化模块 2 读出的拟合力（池化 NCF 路径 + 目标感知残差并联，或 per-concept scorer 加入习题嵌入），再测 m1 增量。
2. 处理门控饱和：题级构成感知融合（模块 2 设计里本有）替代全局 w_u，或对 w 加覆盖率先验正则。
3. DOA / 掌握度评测（模块 2/3 的真正判据），用 `--v2-target-aware-readout` 的 mastery 输出。
4. checkpoint 选择指标敏感性（loss vs auc）复测模块 1。
5. m2 系补 seeds；B0/v1_official 补 seeds。

# 追加：r6（混合读出/题级融合）与 DOA 评测（同日晚）

## r6：留出划分 zero 桶（3 seeds）

| 配置 | zero AUC | overall AUC | 备注 |
|---|---|---|---|
| hybrid（池化 NCF + 零初始化目标感知残差 + 掌握度头） | 0.7381 ± 0.0049 | 0.7505 ± 0.0037 | 补回 m2 缺口的 2/3（0.7173→0.7381），overall 与 base 持平 |
| tfusion（题级构成感知融合残差） | 0.7376 ± 0.0027 | 0.7478 ± 0.0013 | 稳定、小幅低于 base |
| hybrid+模块1 | 0.7370 ± 0.0037 | 0.7486 ± 0.0024 | m1 的 +1.1pt 增益在 hybrid 下消失（见解读） |
| tfusion+模块1 | 0.6671 ± 0.1291 | — | **seed 2025 发散**（AUC 0.504）；健康 seeds 0.749-0.753 |

解读：hybrid 一旦提供强池化通路，梯度倾向绕开零初始化的目标感知残差，模块 1 的信号再次被静音——**拟合力与个性化压力此消彼长**，是下一步设计要正面处理的张力。tfusion+m1 的 1/3 发散率提示该组合需要门控初始化/warmup 修复。

## DOA 评测（scripts/evaluate_doa.py，105 个留出知识点、15.6 万学生对）

Holdout DOA（对留出学生-知识点对的排序力）：
- **无模块 1 的所有配置（m2、mono、hybrid、B0）：精确 = 0.5**——全平局。这是 P1（UKC 学生无关）的构造性实测证明，也是 B0 在留出知识点上无信息的验证；该指标本身可作为论文的诊断工具贡献。
- 带模块 1：产生学生间差异（非平局），但排序质量**接近随机且跨 seed 不稳**——m2+m1(2层) 三 seeds：0.512 / 0.491 / 0.516；hybrid+m1：0.512 / 0.491 / 0.509。均值 ≈0.505 ± 0.012。
- 标准 DOA（有证据知识点）：B0 0.586 全场最高（计数排序强）；m2 掌握度头无单调约束时 0.48（低于随机，语义可翻转）；**加单调约束（模块 3a）回到 0.51**——可辨识性问题的直接实测，支持单调约束。

## KaNCD 基线（in-harness 复现，--model kancd；修复了正权层初始化饱和 bug）
assist09_chold（3 seeds，minibatch 训练）：overall AUC 0.7248 / zero 0.6835（预测比我们低 5-6pt），但 **holdout DOA 0.5765±0.0128、标准 DOA 0.62**——低秩外推在 assist09 的诊断轴上大幅领先我们（我们≈0.50）。审稿报告的 M4 攻击应验：KaNCD 不在"两难困境"里。

**核心结论：在证据/结构密集的数据集上，解耦完整栈在两个诊断轴上同时击败 KaNCD（holdout DOA 0.651 vs 0.601）且预测持平。** assist09 上的诊断轴失利主要是数据集信号问题（共现图稀疏、证据稀薄），印证"数据集选择本身是实验变量"。

## 两数据集对照的叙事格局
- assist09（稀疏）：我们赢预测轴（zero AUC +6pt），KaNCD 赢诊断轴（holdout DOA +7.7pt）；
- nips34（密集）：我们两轴全赢或持平。
- 明确的下一步架构综合：掌握度头改为"低秩全局外推 + 图传播个性化修正"（mastery = σ(⟨u_s,c_k⟩ + w·h_{s,k})），既吃 KaNCD 的外推底座，又保留解耦修正——目标是在稀疏数据集上也拿下诊断轴。

## 修正与结论更新

- 早前"模块 1(2层) 是唯一 holdout DOA > 0.5 的配置"系单 seed 结论，多 seed 后**不成立**（2/3 seeds 为正、1/3 为负）。成立的是结构性发现：模块 1 是唯一产生留出个性化（非平局）的机制。
- 核心诊断：**当前损失中没有任何项对 UKC 侧掌握度施加训练压力**（BCE 只作用于有作答的交互），个性化状态排序接近随机是预期后果。下一个明确杠杆 = 研究计划中的模块 4 弱版本（掩码 TKC→伪 UKC 的状态一致性目标，不接触标签，保住"无直接行为监督"主张），给模块 1 提供针对推断状态的训练信号。
- 读出层结论：hybrid 可作为论文默认读出（拟合持平 + 掌握度输出）；单调约束应默认开启（掌握度定向）；tfusion 备选。
