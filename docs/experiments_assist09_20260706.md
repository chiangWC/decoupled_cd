## 结论

1. **砍适配器是目前最大的单一正效应**：v1 全适配器在 zero 桶稳定垫底（两种划分一致，−2.4~−2.5pt vs 裸核/base），其整体涨幅完全来自有历史证据的切片。适配器 = 计数补丁、非诊断能力，实证成立。
2. **B0 角色反转（论文动机素材）**：随机划分整体 AUC 全场第一；留出 zero 桶跌至中游（目标知识点计数被构造归零）——但校准（Brier/ECE）仍全场最佳。整体 AUC 战场属于计数统计，未测知识点排序战场才属于结构模型。
3. **模块 1（TKC→UKC 个性化传播）单独无效，但机制有信号**：
   - 单独加：与 v2 base 完全持平（5 seeds，CI 重叠）；残差权重范数 3.0-3.9（与静态变换同量级）——通路被训练激活，非优化失败。
   - 机制解释（双重静音）：(a) base 读出只经 `mean(UKC 全部概念)` 消费逐知识点状态，个性化被 ~120× 稀释；(b) gate 诊断显示融合门饱和于 TKC 侧（mean w=0.92，UKC 贡献范数 1/11，corr(coverage,w)=0.14）。
   - 配合模块 2（读出可见逐知识点状态）时 **+1.1pt**（m2+m1 0.7285 vs m2 单独 0.7173，~1.5σ，方向在 1/2 层一致）——个性化信号存在，但需要能消费它的读出。
4. **模块 2（目标感知读出）拟合力缺口是当前瓶颈**：单独 −2.4pt vs base（zero 桶）。它解锁掌握度输出/DOA（价值判据未跑），但作为预测头明显弱于池化 NCF。加模块 1 可回补一半缺口，仍低于 base。
5. **模块 3**：3a（单调）在模块 2 之上小幅为正且 ECE 改善；3b（有界 g/s）中性偏负。价值判据（可辨识性/DOA）未跑。

## 已知方法学局限

- checkpoint/早停按**整体** valid AUC 选择，对"牺牲整体换 zero 桶"的模块方向存在系统性选择偏差（待用 loss/分桶指标复测）。
- m2 系仅 3-4 seeds，±1pt 级差异需补 seeds。
- zero 桶 label_rate（0.787）与 full 桶（0.654）不同，桶间不可比，仅同桶跨模型比较有效。
- B0/v1_official 尚为单 seed。
