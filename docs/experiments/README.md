# Experiment Detail Notes

This directory is a pilot for keeping `docs/model_improvement_plan.md` dense.

Use this directory only for experiments whose details are still useful for future decisions. Keep the main plan as the high-signal index and put supporting seed rows, diagnostics, commands, and failure-mode evidence here.

Recommended detail status values for `docs/experiment_index.jsonl`:

- `local_detail_doc`: detailed notes are available in this directory.
- `compressed_only`: only the compressed main-plan summary is available.
- `recoverable_from_git`: older uncompressed notes may exist in git history.
